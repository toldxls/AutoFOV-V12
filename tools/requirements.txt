# Optional build-time dependencies for tools/embed_html.py.
#
# Non-destructive minifiers (comment + whitespace only — they never rename
# identifiers) that shrink the embedded dashboard before gzip, taking ~46 KB
# off the firmware binary. embed_html.py falls back to un-minified HTML if they
# are absent, so these are optional — but without them every build silently
# ships a larger image. Install once with:
#
#   pip3 install -r tools/requirements.txt
#
