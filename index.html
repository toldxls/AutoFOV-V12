AutoFOV V12 — USB Recovery Flash

Use this only if the device won't start or its web dashboard is unreachable. For a normal update, use Update from GitHub on the dashboard instead.

You need

  • A computer running Google Chrome or Microsoft Edge (Safari and Firefox can't flash over USB).
  • A data-capable USB-C cable — some cables are charge-only and will not work.

Steps

  1. Plug the device into the computer with the USB-C cable.
  2. Click Recovery Flash below.
  3. In the popup, pick the device's serial port and click Connect.
  4. Click Install and wait — do not unplug until it finishes.
  5. The device reboots into working firmware on its own.
This browser can't flash over USB — open this page in Chrome or Edge. Flashing needs a secure (https) connection — open the published GitHub Pages link, not a local file.
Recovery keeps your calibration and WiFi settings — it rewrites the bootloader, partition table and firmware but leaves the saved-settings region alone.

If the device isn't listed in the popup

The ESP32-S3 normally enters flashing mode by itself. If no port appears, put it in flashing mode by hand:

  1. Hold the BOOT button down.
  2. Briefly press and release RESET.
  3. Release BOOT.
  4. Click Recovery Flash again — the port should now appear.
Do not use the Arduino IDE's Upload button to recover — it can overwrite the partition layout. This page (or tools/flash_firmware_only.sh) is the safe route.
